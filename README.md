PivotBoss-aligned trading execution dashboard for Market Profile & Central Pivot Range (CPR) context analysis.

---

## 📊 Overview

The Command Center provides pre-market and intra-day scenario coverage using:
- **PivotBoss methodology** — Floor pivots, CPR, Camarilla, Value Area
- **Volume Profile** — Spot/futures volume histogram with POC/VAH/VAL
- **Two-day CPR relationship** — Higher/Lower/Overlapping/Inside/Outside
- **7 opening cases** (A-E) with primary/contingency trade plans

## 🔄 Automated Workflows

### Daily Pivot Update
- **Schedule**: Weekdays at 6:00 PM IST
- **Trigger**: `.github/workflows/daily-pivot.yml`
- **Action**: Runs `pivot_boss.py`, commits updated `public/data/NIFTY.json`

### Live Market 9:30 AM Update
- **Schedule**: Weekdays at 9:30 AM IST
- **Trigger**: `.github/workflows/live-market.yml`
- **Action**: Runs `live_market.py`, updates `opening_classification` and `first_15m_candle`

> **Note**: Both workflows skip execution on weekends and NSE holidays.

### `opening_classification` Expectations

#### Pre-Market Phase (Before 09:15 AM)
Set `opening_classification` to `"PENDING"` when running your pre-market analysis script.
```json
"opening_classification": "PENDING"
```
*The dashboard will display a yellow `PRE-MARKET PREPARATION` badge and prompt the trader to review all 5 playbooks.*

#### Post-Market Open Phase (After 09:15 AM)
Update `opening_classification` to one of the 5 PivotBoss opening states based on where NIFTY opens relative to the Value Area (`VAL` to `VAH`) and Session Range (`PDL` to `PDH`):

| Enum Value | Opening Condition | Playbook Triggered |
| :--- | :--- | :--- |
| `"IN_VALUE"` | `PDL <= Open <= PDH` AND `VAL <= Open <= VAH` | **CASE A · IN RANGE / VALUE** |
| `"ABOVE_VALUE"` | `PDL <= Open <= PDH` AND `Open > VAH` | **CASE B · IN RANGE / ABOVE VALUE** |
| `"BELOW_VALUE"` | `PDL <= Open <= PDH` AND `Open < VAL` | **CASE C · IN RANGE / BELOW VALUE** |
| `"OUT_ABOVE"` | `Open > PDH` | **CASE D · ABOVE PDH (Gap Up)** |
| `"OUT_BELOW"` | `Open < PDL` | **CASE E · BELOW PDL (Gap Down)** |

Example:
```json
"opening_classification": "BELOW_VALUE"
```

### `first_15m_candle` Expectations

#### Pre-Market Phase (Before 09:30 AM)
Set to `null` before the first 15-minute candle closes.
```json
"first_15m_candle": null
```

#### Post-Market Open Phase (After 09:30 AM)

##### Extended Format (Recommended):
```json
"first_15m_candle": {
  "open": 24520.00,
  "high": 24565.50,
  "low": 24510.25,
  "close": 24548.10,
  "volume": 1250000,
  "type": "BULLISH",           // "BULLISH" | "BEARISH" | "DOJI"
  "acceptance": "INSIDE_VALUE" // "INSIDE_VALUE" | "ABOVE_VALUE" | "BELOW_VALUE" | "REJECTED"
}
```

## 📖 PivotBoss Methodology

1. **Pivots**: Floor pivot points + Central Pivot Range (CPR)
2. **Camarilla**: H1-H5, L1-L5 levels for reversals and breakouts
3. **Value Area**: Volume Profile-based VAH, POC, VAL via futures volume
4. **Width Analysis**: CPR/VA/Camarilla widths indicate TREND (narrow) vs RANGE (wide)
5. **Two-Day CPR**: Higher/Lower/Overlapping/Inside/Outside → market bias
6. **Opening Classification**: 5 cases (A-E) + detailed location
7. **Scenario Generation**: Cases, triggers, hot zones, no-trade rules

Reference: `PivotBoss_Market_Implementation_Playbook.md`

## 🆘 Troubleshooting

### "Could not fetch today's data via V3 intraday"
Market may still be open or data not yet available. Run after 3:30 PM IST.

### "Need at least 2 daily bars"
Upstox V2 daily API may be delayed. Ensure `FORCE_REFRESH_NSE_HOLIDAYS=1` is not needed.

### Token expiry (401/UDAPI100050)
`UpstoxClient` auto-refreshes on 401. If persistent, re-run login:
```bash
python -c "import sys; sys.path.insert(0, 'api'); from upstox_login import login; login()"
```
